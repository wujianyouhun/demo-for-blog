# 深入U-Net——遥感语义分割的技术核心

前两篇文章让你了解了遥感语义分割的应用价值并成功跑通了训练流程。这篇文章我们将深入代码内部，逐层剖析 U-Net 的架构设计、损失函数的数学原理、评价指标的计算过程，以及数据增强和训练策略背后的考量。理解了这些技术细节，你不仅能更好地使用这个项目，还能在面对新问题时做出合理的调整和优化。

## U-Net 架构详解——从像素到语义的编码之旅

U-Net 的整体架构可以分为三大模块：编码器（Encoder）、瓶颈层（Bottleneck）和解码器（Decoder）。编码器负责逐层提取图像特征并缩小空间尺寸，瓶颈层在最深处捕获全局语义信息，解码器则逐步恢复空间分辨率并生成最终的分割图。三者通过跳跃连接（Skip Connection）紧密配合，构成了一个"先压缩、再展开、中间传话"的信息处理流水线。

让我们从编码器的第一个模块 ConvBlock 开始分析。ConvBlock 是 U-Net 中最基础的构建单元，它的核心思想是"两次3×3卷积+批归一化+ReLU激活"的组合。这个设计看起来简单，但每一个组件都有明确的作用。

```python
class ConvBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_ch, out_ch, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True),
        )

    def forward(self, x):
        return self.conv(x)
```

3×3卷积核是深度学习中的经典选择。它足够小，计算效率高；通过堆叠两个3×3卷积，可以获得等效于5×5卷积的感受野（即每个输出像素"看到"的输入区域），但参数量更少。`padding=1` 确保卷积操作后特征图的尺寸不变——输入的 H×W 输出仍然是 H×W，这对于需要精确像素级预测的分割任务至关重要。

`bias=False` 的设置不是随意的：因为紧跟卷积之后的是 BatchNorm 层，BatchNorm 本身有一个可学习的偏置参数，如果卷积也带偏置，就会出现冗余参数，浪费计算资源。这是一种小而精的工程实践。

BatchNorm（批归一化）对每个通道的特征做标准化处理——减去均值、除以方差，然后通过两个可学习参数进行缩放和平移。它的作用是让训练更稳定：在没有 BatchNorm 的情况下，深层网络的中间层输入分布会随着参数更新而剧烈变化（称为"内部协变量偏移"），导致训练困难。BatchNorm 通过归一化操作缓解了这个问题，同时还有轻微的正则化效果，有助于防止过拟合。

ReLU（Rectified Linear Unit）是最常用的激活函数，它的数学表达式极其简单：`f(x) = max(0, x)`。负值变为0，正值不变。这个简单的操作为网络引入了非线性——如果没有激活函数，无论堆叠多少层卷积，整个网络最终都等价于一个线性变换，无法学习复杂的模式。ReLU 的优点是计算快、梯度不会像 Sigmoid 那样在正区间饱和（有助于缓解梯度消失问题），而且通过"杀死"负值，天然地引入了一定的稀疏性。

## 下采样——逐步抽象的编码器

编码器中的下采样通过 DownBlock 实现。每个 DownBlock 先用一个2×2的最大池化（MaxPool）将特征图的高和宽各缩小一半，然后通过 ConvBlock 进行特征提取。

```python
class DownBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.pool = nn.MaxPool2d(2)
        self.conv = ConvBlock(in_ch, out_ch)

    def forward(self, x):
        return self.conv(self.pool(x))
```

MaxPool 的工作原理是在特征图上滑动一个2×2的窗口，每个窗口内只保留最大值。这个过程有两个效果：第一，特征图尺寸减半（比如从256×256变成128×128），减少了后续计算量；第二，最大值代表了该局部区域内最显著的特征响应，相当于做了信息的"筛选"——保留最突出的信号，丢弃不重要的细节。

随着编码器一层层向下推进，特征图的变化遵循一个清晰的规律：空间尺寸不断缩小（256→128→64→32→16），通道数不断增加（64→128→256→512→1024）。空间尺寸的缩小意味着"视野"变大——深层的特征图上每个像素对应原始图像中更大的区域；通道数的增加意味着"描述能力"变强——更多的通道可以编码更丰富的语义信息。

这种设计的直觉可以类比人类看地图的过程。当你把地图缩得很小（相当于深层特征图），你看不清具体的建筑细节，但能把握整体的城市格局——哪里是密集的城市区，哪里是大片的农田或森林。这正是编码器想要实现的：在深层获取全局的语义理解。

## 上采样与跳跃连接——细节恢复的关键

解码器中的 UpBlock 是 U-Net 的精华所在。它需要完成两件事：第一，把深层的小尺寸特征图放大回较大的尺寸（上采样）；第二，把编码器对应层的特征拼接过来（跳跃连接），补充在放大过程中丢失的空间细节。

```python
class UpBlock(nn.Module):
    def __init__(self, in_ch, skip_ch, out_ch, bilinear=True):
        super().__init__()
        if bilinear:
            self.up = nn.Upsample(scale_factor=2, mode="bilinear", align_corners=True)
            self.conv = ConvBlock(in_ch + skip_ch, out_ch)
        else:
            self.up = nn.ConvTranspose2d(in_ch, in_ch // 2, 2, stride=2)
            self.conv = ConvBlock(in_ch // 2 + skip_ch, out_ch)

    def forward(self, x1, x2):
        x1 = self.up(x1)
        # 处理尺寸不匹配的情况
        diff_h = x2.size(2) - x1.size(2)
        diff_w = x2.size(3) - x1.size(3)
        x1 = F.pad(x1, [diff_w // 2, diff_w - diff_w // 2,
                         diff_h // 2, diff_h - diff_h // 2])
        x = torch.cat([x2, x1], dim=1)  # 通道维度拼接
        return self.conv(x)
```

代码中提供了两种上采样方式。双线性插值（bilinear interpolation）是一种固定算法，它通过周围四个像素的加权平均来计算新像素值，优点是计算量小、输出稳定，缺点是没有可学习参数，完全依赖固定的插值公式。转置卷积（ConvTranspose2d）则是一种可学习的上采样方式，它通过学习的卷积核来"填充"放大后的特征，理论上效果更好但参数更多。本项目默认使用双线性插值，因为它更稳定且计算开销更小。

`forward` 方法接收两个输入：`x1` 是来自深层（解码器上一层）的特征，`x2` 是来自编码器对应层的跳跃连接特征。在拼接之前，代码仔细处理了尺寸可能不完全匹配的问题——由于多次下采样和上采样，当输入图像尺寸不是2的幂次时，特征图的尺寸可能出现奇偶差异。通过计算差值并用 `F.pad` 做填充，确保两个特征图可以精确对齐。

`torch.cat([x2, x1], dim=1)` 是跳跃连接的核心操作——在通道维度（dim=1）上将编码器特征和解码器特征拼接在一起。比如编码器某层输出128个通道，解码器上采样后也有512个通道，拼接后就变成了640个通道，然后送入 ConvBlock 进行特征融合和降维。这样，解码器不仅有了深层的语义信息（"这个区域大概是什么类别"），还获得了浅层的空间信息（"这个区域的精确边界在哪里"），从而能够生成边界清晰的分割结果。

## 完整的前向传播流程

将编码器和解码器组合在一起，UNet 类定义了完整的前向传播路径：

```python
class UNet(nn.Module):
    def __init__(self, in_channels=3, num_classes=7):
        super().__init__()
        self.enc1 = ConvBlock(in_channels, 64)
        self.enc2 = DownBlock(64, 128)
        self.enc3 = DownBlock(128, 256)
        self.enc4 = DownBlock(256, 512)
        self.bottleneck = DownBlock(512, 1024)
        self.up4 = UpBlock(1024, 512, 512)
        self.up3 = UpBlock(512, 256, 256)
        self.up2 = UpBlock(256, 128, 128)
        self.up1 = UpBlock(128, 64, 64)
        self.final = nn.Conv2d(64, num_classes, kernel_size=1)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(e1)
        e3 = self.enc3(e2)
        e4 = self.enc4(e3)
        b = self.bottleneck(e4)
        d4 = self.up4(b, e4)
        d3 = self.up3(d4, e3)
        d2 = self.up2(d3, e2)
        d1 = self.up1(d2, e1)
        out = self.final(d1)
        return out
```

整个前向传播的过程可以用一条清晰的流水线来描述。输入图像 (3, 256, 256) 首先经过编码器，依次产生 e1 (64, 256, 256)、e2 (128, 128, 128)、e3 (256, 64, 64)、e4 (512, 32, 32) 四个中间特征图，并继续下采样到瓶颈层 b (1024, 16, 16)。然后解码器开始工作：b 上采样后与 e4 拼接产生 d4 (512, 32, 32)，d4 上采样后与 e3 拼接产生 d3 (256, 64, 64)，以此类推，直到 d1 (64, 256, 256)。最后通过一个1×1卷积（`self.final`）将64个通道映射到7个类别通道，输出形状为 (7, 256, 256)。

最后的1×1卷积是"分类头"——它对每个像素位置的64维特征向量做一次线性变换，输出7个数值（称为 logits），代表该像素属于每个类别的"得分"。训练时这些 logits 会被送入损失函数计算误差；推理时取最大的那个得分对应的类别作为预测结果。

## 损失函数设计——交叉熵与 Dice Loss 的组合

损失函数是训练过程中引导模型学习方向的"指南针"——它衡量模型预测与真实标签之间的差距，优化器通过最小化损失来更新模型参数。本项目使用了一个组合损失函数，将交叉熵损失和 Dice Loss 相加，兼顾像素精度和区域一致性。

```python
class CombinedLoss(nn.Module):
    def __init__(self, num_classes, class_weights=None):
        super().__init__()
        self.ce = nn.CrossEntropyLoss(
            weight=torch.tensor(class_weights, dtype=torch.float32) if class_weights else None,
            ignore_index=255
        )
        self.num_classes = num_classes

    def forward(self, pred, target):
        ce_loss = self.ce(pred, target)
        pred_soft = F.softmax(pred, dim=1)
        target_onehot = F.one_hot(target.clamp(0, self.num_classes - 1), self.num_classes).permute(0, 3, 1, 2).float()
        dice = 0
        for c in range(self.num_classes):
            p = pred_soft[:, c]
            t = target_onehot[:, c]
            inter = (p * t).sum()
            union = p.sum() + t.sum()
            if union > 0:
                dice += (2 * inter + 1) / (union + 1)
        dice_loss = 1 - dice / self.num_classes
        return ce_loss + dice_loss
```

交叉熵损失（Cross Entropy Loss）是分类任务中最基础的损失函数。它对每个像素独立计算预测概率分布与真实标签之间的差异。直觉上，如果模型对某个像素的预测概率分布高度集中在正确的类别上，交叉熵就小；如果预测概率分散或集中在错误的类别上，交叉熵就大。交叉熵的优势是对每个像素的预测都很敏感，能有效驱动模型提高像素级的分类精度。

Dice Loss 源自医学图像分割领域，它的核心思想是衡量预测区域和真实区域的重叠程度。Dice 系数的公式是 `2 × |A ∩ B| / (|A| + |B|)`，其中 A 是预测为某类别的像素集合，B 是真实标签中该类别的像素集合。当预测完全正确时 Dice=1，完全不重叠时 Dice=0。Dice Loss = 1 - Dice。

为什么要组合使用两种损失？因为它们在类别不平衡的场景下各有优劣。交叉熵对每个像素等权计算，当某个类别的像素占比很小（比如道路只占图像的5%）时，该类别对总损失的贡献很小，模型容易忽略它。而 Dice Loss 是基于集合重叠计算的，即使某个类别只占很少的像素，只要预测不准，Dice Loss 依然会给出很大的惩罚。两者结合，既保证了像素级精度，又照顾到了稀有类别的分割质量。

代码中还有一个值得注意的细节：`ignore_index=255`。在遥感标注中，某些像素可能没有被标注（比如云层遮挡区域），这些像素的标签通常被标记为255。设置 `ignore_index=255` 让损失函数在计算时自动跳过这些未标注像素，避免它们对模型训练产生误导。

## 评价指标——mIoU 和 OA 的计算过程

语义分割的评价指标是衡量模型好坏的"标尺"。本项目使用两个核心指标：Overall Accuracy（OA，总体精度）和 mean Intersection over Union（mIoU，平均交并比）。这两个指标都是从混淆矩阵推导出来的。

```python
def compute_metrics(pred, target, num_classes):
    pred = pred.argmax(dim=1)  # (B, H, W)
    confusion = torch.zeros(num_classes, num_classes, dtype=torch.long)
    for t, p in zip(target.view(-1), pred.view(-1)):
        if 0 <= t < num_classes and 0 <= p < num_classes:
            confusion[t, p] += 1
    oa = confusion.diag().sum().float() / (confusion.sum() + 1e-8)
    ious = []
    for c in range(num_classes):
        tp = confusion[c, c].float()
        fp = confusion[:, c].sum().float() - tp
        fn = confusion[c, :].sum().float() - tp
        iou = tp / (tp + fp + fn + 1e-8)
        ious.append(iou.item())
    miou = np.mean(ious)
    return {"OA": oa.item(), "mIoU": miou, "class_IoU": ious}
```

混淆矩阵是一个 `num_classes × num_classes` 的方阵，矩阵第 i 行第 j 列的值表示"真实类别是 i 但被预测为 j"的像素数量。对角线上的元素就是预测正确的像素数。OA 的计算很简单：所有对角线元素之和除以所有元素之和。直观理解就是"预测对的像素占总像素的比例"。

IoU（Intersection over Union）的计算更加精细。对于每个类别，IoU = TP / (TP + FP + FN)，其中 TP 是真阳性（正确预测为该类别的像素），FP 是假阳性（不是该类别但被预测为该类别的像素），FN 是假阴性（是该类别但被预测为其他类别的像素）。分母 TP + FP + FN 实际上就是"预测为该类别的像素"和"真实为该类别的像素"的并集，分子是它们的交集。

mIoU 就是所有类别 IoU 的平均值。它是语义分割领域最受认可的指标，因为它对每个类别"一视同仁"——即使某个类别的像素占比很大（如背景），它的 IoU 也不会主导最终结果。一个模型如果在大类上表现好但在小类上表现差，mIoU 会给出一个更真实的评估。

## 数据增强策略——让模型见过更多变化

数据增强是提升模型泛化能力的重要手段。通过对训练数据施加随机但合理的变换，可以让模型在训练过程中看到更多"变体"，从而提高它对各种场景的适应能力。本项目中的数据增强在 `LandCoverDataset` 的 `_augment` 方法中实现。

```python
def _augment(self, image, label):
    # 随机水平翻转
    if random.random() > 0.5:
        image = np.flip(image, axis=1).copy()
        label = np.flip(label, axis=0).copy()
    # 随机垂直翻转
    if random.random() > 0.5:
        image = np.flip(image, axis=0).copy()
        label = np.flip(label, axis=1).copy()
    # 随机 90° 旋转
    k = random.randint(0, 3)
    if k > 0:
        image = np.rot90(image, k, axes=(0, 1)).copy()
        label = np.rot90(label, k, axes=(0, 1)).copy()
    # 颜色抖动（仅对图像）
    if random.random() > 0.5:
        brightness = random.uniform(0.9, 1.1)
        image = np.clip(image * brightness, 0, 1)
    return image, label
```

数据增强最重要的原则是"图像和标签必须同步变换"——如果你对影像做了水平翻转，标签也必须做同样的翻转，否则像素和类别就错位了。代码中的几何变换（翻转和旋转）同时作用于影像和标签，保证了这种对齐关系。

随机翻转和旋转对于遥感影像是特别合理的增强方式。与日常照片不同，卫星影像没有固定的"上下左右"方向——从太空俯瞰地球，同一个区域从不同角度拍摄看起来是一样的。因此水平和垂直翻转、90度旋转都不会改变影像的语义含义，但能给模型提供更多视角的训练样本。

颜色抖动只对影像做处理（标签不需要变），通过随机调整亮度来模拟不同光照条件下的影像差异。遥感影像的亮度受太阳高度角、云层遮挡、季节变化等因素影响，同一地区在不同时间拍摄的影像亮度可能差异很大。通过颜色抖动让模型学会"忽略亮度差异，关注地物本质特征"。

## 训练策略——余弦退火、梯度裁剪与早停

除了模型架构和损失函数，训练策略的选择也直接影响最终效果。本项目采用了三种经过实践验证的训练技巧。

余弦退火学习率调度器通过 `CosineAnnealingLR` 实现，它让学习率按照余弦曲线的形状从初始值平滑下降到接近零。具体来说，如果初始学习率是 1e-4，训练30个 epoch，那么第 k 个 epoch 的学习率约为 `1e-4 × 0.5 × (1 + cos(k/30 × π))`。这种策略的好处是：训练初期学习率大，模型可以快速接近一个好的解；训练后期学习率小，模型可以在好的解附近精细调整，避免大幅震荡。

```python
self.scheduler = optim.lr_scheduler.CosineAnnealingLR(
    self.optimizer, T_max=config.epochs, eta_min=config.lr * 0.01
)
```

梯度裁剪（Gradient Clipping）通过 `clip_grad_norm_` 实现，它将梯度的范数限制在一个最大值以内。在深度网络训练中，偶尔会出现某些批次的梯度异常大的情况（梯度爆炸），导致参数更新过猛、损失突然飙升。梯度裁剪相当于给参数更新加了一个"限速器"——正常情况下不影响训练，异常时防止参数跳变。

```python
torch.nn.utils.clip_grad_norm_(self.model.parameters(), max_norm=1.0)
```

早停机制（Early Stopping）通过监控验证集上的 mIoU 来决定何时停止训练。代码中的实现是：每轮验证后检查 mIoU 是否超过了历史最优值，如果是则重置耐心计数器并保存模型权重；如果不是，耐心计数器加1。当计数器达到设定的耐心值（默认8）时，训练自动停止。这种机制有效防止了过拟合——当模型开始在训练集上"死记硬背"而验证集上表现变差时，训练会及时终止，保留的是验证集上表现最好的那个模型。

```python
if val_miou > self.best_miou:
    self.best_miou = val_miou
    self.patience_counter = 0
    torch.save({...}, save_path)
else:
    self.patience_counter += 1
if self.patience_counter >= self.config.patience:
    print("[EARLY STOP] 停止训练")
    break
```

这三种策略的组合构成了一个稳健的训练系统：余弦退火保证学习过程平滑高效，梯度裁剪防止意外崩溃，早停机制避免过拟合。它们各自独立却又协同工作，体现了深度学习工程中"多个简单技巧组合出好结果"的实践哲学。掌握了这些技术细节，你不仅理解了本项目的工作原理，更为将来使用更复杂的模型和数据集打下了坚实的基础。
