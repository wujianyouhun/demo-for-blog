# 遥感变化检测——发现地球表面的每一次改变

你是否玩过"找不同"游戏？两张看似相同的图片摆在你面前，你需要仔细观察每一个细节，找出它们之间的差异——也许是角落里多了一朵花，也许是墙上的时钟不见了，也许是天空中的云彩换了形状。这个游戏考验的是你的观察力和对细节的敏感度。

遥感变化检测，本质上就是一台超级计算机在玩"找不同"。只不过它要找的不是卡通画里的差异，而是地球表面在不同时间点发生的真实变化——哪里新盖了一片楼房，哪里砍掉了一片森林，哪里的湖泊因为干旱缩小了面积。这些变化对我们的生活、对环境、对整个社会都有着深远的影响。

![遥感影像对比示例](http://q9.itc.cn/q_70/images03/20260407/3716274aee01439cb2329f825f4541c6.png)

想象一下你有一台时光相机，能在同一地点、不同角度拍下两张照片，一张是2010年的城市街景，一张是2020年的。你一眼就能看到：那条小路变成了宽阔的柏油马路，那片空地建起了高楼大厦，那个池塘被填平变成了停车场。遥感变化检测做的就是同样的事情，只不过"时光相机"是卫星或无人机，而"找不同"的工作交给了人工智能。

## 为什么我们需要变化检测

变化检测听起来像是一个学术研究课题，但它与我们的日常生活息息相关。让我们从几个真实的应用场景来理解它的价值。

城市扩张监测是最直观的应用。中国过去四十年的城市化进程是人类历史上最大规模的人口迁移之一。从卫星视角看去，深圳从一个渔村变成了拥有两千万人口的超级都市，浦东新区从农田变成了金融中心。城市规划者需要准确知道城市边界在哪里扩展了，哪些农田被转化成了建设用地，新开发区域的密度如何。传统的人工调查费时费力，而遥感变化检测可以在几小时内覆盖数百平方公里的范围，精准地标记出每一处变化。

![城市扩张的卫星视角对比](http://gips2.baidu.com/it/u=1738346851,3031998529&fm=3074&app=3074&f=JPEG?w=1080&h=1409&type=normal&func=)

灾害评估是变化检测的另一个关键应用。2008年汶川地震后，救援人员需要第一时间知道哪些房屋倒塌了、哪些道路被阻断了、哪些山体发生了滑坡。通过对比灾前和灾后的卫星影像，变化检测算法可以迅速生成受灾地图，指导救援力量的部署。同样的技术也应用于洪水监测——对比洪灾前后的水体范围变化，可以评估淹没面积和受灾人口。2021年河南暴雨期间，多家遥感机构就是通过变化检测技术快速评估了灾情的。

违建检测是城市管理中的一个重要应用。在一些城市，未经审批的违章建筑是一个长期困扰城市治理的问题。通过定期的航拍或卫星影像变化检测，城市管理部门可以自动发现新增的建筑物，比对规划许可数据库，快速识别出违章建筑。这种"天眼"式的监管手段比传统的人工巡查效率高出一个数量级。

森林砍伐追踪在全球气候变化背景下尤为重要。亚马逊雨林每年都有大面积被非法砍伐，传统的森林巡逻在广袤的热带雨林中几乎不可能覆盖所有区域。而通过定期的卫星影像变化检测，环保组织可以近实时地发现新的砍伐区域，甚至可以通过分析砍伐模式和速度来预测下一步可能发生砍伐的区域。全球森林观察（Global Forest Watch）就是这样一个利用变化检测技术运行的平台，它为全世界的森林保护提供了重要的数据支撑。

## LEVIR-CD数据集：我们的训练素材

任何人工智能模型都需要数据来"学习"，变化检测也不例外。本项目使用的是LEVIR-CD数据集，这是遥感变化检测领域最知名的基准数据集之一。

LEVIR-CD的全称是"Large-scale High-Resolution Building Change Detection Dataset"，由武汉大学的研究团队发布。它包含了637对高分辨率的双时相航空影像，每对影像的尺寸为1024×1024像素，空间分辨率为0.5米/像素。这些影像覆盖了美国德克萨斯州多个城市区域，时间跨度从2002年到2018年，横跨了16年的城市发展历程。

"双时相"这个概念需要解释一下。所谓"时相"（temporal phase），就是同一地点在不同时间拍摄的影像。"双时相"意味着我们有两张同一地点、不同时间的影像——我们称之为时相A和时相B。LEVIR-CD的标注是二值变化标签：每个像素要么标记为"变化"（值为1），要么标记为"未变化"（值为0），变化类型主要是建筑物的增减——新建的楼房、拆除的建筑、扩建的停车场等。

为什么选择这个数据集？首先，它的高分辨率（0.5米/像素）让我们可以清晰地看到建筑物级别的细节变化；其次，637对影像的规模足够用来训练和评估深度学习模型；更重要的是，它反映的是真实的城市场景变化，而不是人工合成的数据，这使得在这个数据集上训练的模型具有实际应用的参考价值。

在本项目中，由于LEVIR-CD原始数据需要单独下载，我们使用了合成数据作为教学演示。合成数据模拟了LEVIR-CD的核心特征：双时相影像对、建筑变化、二值标签。通过合成数据，你可以在不需要额外下载的情况下快速上手，理解变化检测的完整流程。当你掌握了基本原理后，再用真实的LEVIR-CD数据训练就会变得得心应手。

## 孪生网络：变化检测的核心思想

现在让我们聚焦于这个项目的技术核心——孪生网络（Siamese Network）。

"孪生"这个词来自双胞胎。就像双胞胎拥有相同的面容和身体结构一样，孪生网络也有两个结构完全相同的"分支"。在变化检测的场景下，一个分支"看"时相A的影像，另一个分支"看"时相B的影像。关键在于，这两个分支共享完全相同的权重参数——也就是说，它们用"同一双眼睛"去观察两个不同时间的世界。

为什么要共享权重？这背后有一个深刻的直觉：我们希望模型能够用相同的标准去"理解"两个时相的影像。如果A和B使用不同的编码器，那么即使同一个物体在两个时相中完全相同，提取出的特征也可能不同，模型就会产生混淆。而共享编码器确保了"看到同样的东西就产生同样的特征"，这样当特征出现差异时，这个差异就更有可能是真正的地表变化，而不是编码方式的差异造成的。

![孪生网络架构示意图](http://upload-images.jianshu.io/upload_images/21382510-7804dfe82ab26cf8.png)

整个流程可以这样描述：时相A的影像通过共享编码器提取出一组多层次的特征图，时相B的影像也通过同样的编码器提取出对应的特征图。然后在每一层上，计算两个时相特征的绝对差值——这个差值就代表了"变化的信号"。差值大的地方，说明两个时相在这个位置发生了明显变化；差值小的地方，说明地表基本保持不变。最后，这些差异特征被送入一个解码器，解码器的任务是把这些差异信息综合起来，生成最终的变化图——一张与输入影像尺寸相同的二值图，每个像素标记为"变化"或"未变化"。

用代码来表达这个核心思想，就是本项目中SiamUNet类的设计：

```python
class SiamUNet(nn.Module):
    """
    孪生 U-Net 变化检测网络

    完整架构：

    时相 A ──┐                     ┌── 差异特征
             ├── 共享编码器 ──→ │   │      │
    时相 B ──┘                 └── 原始特征 ──→ 解码器 ──→ 变化图
    """

    def __init__(self, in_channels=3, num_classes=2):
        super().__init__()
        self.encoder = Encoder(in_channels)
        self.decoder = ChangeDecoder(num_classes)

    def forward(self, img_a, img_b):
        feats_a = self.encoder(img_a)
        feats_b = self.encoder(img_b)
        output = self.decoder(feats_a, feats_b)
        return output
```

这段代码非常简洁，但蕴含了变化检测的全部核心逻辑。`forward`方法接收两张图像`img_a`和`img_b`，它们通过同一个`encoder`提取特征，然后特征差异被送入`decoder`生成变化预测图。整个网络的精髓就在这三行代码中。

## 变化检测与语义分割的区别

如果你之前学习过语义分割（Semantic Segmentation），可能会对变化检测产生一个疑问：这不就是一种特殊的语义分割吗？确实，两者在技术实现上有很多相似之处——都是像素级的分类任务，都使用编码器-解码器架构，都用交叉熵损失训练。但变化检测有几个本质特征使其成为一个独立的研究方向。

最根本的区别在于输入。语义分割的输入是一张图像，目标是把每个像素分类为某个语义类别（如建筑、道路、植被、水体等）。变化检测的输入是两张图像，目标是判断每个像素在两个时间点之间是否发生了变化。这个看似微小的差异，带来了一系列独特的技术挑战。

首先是双时相对齐问题。两张不同时间拍摄的影像必须精确对齐到同一地理坐标系下，否则即使地表没有变化，像素级别的偏移也会产生虚假的变化信号。在真实数据中，由于拍摄角度、季节光照差异、云层遮挡等因素，完美的对齐几乎不可能实现。模型必须学会区分"真实的地表变化"和"伪变化"（由成像条件差异造成的虚假信号）。

其次是类别极度不平衡。在语义分割中，不同类别（如建筑和植被）可能各占一定比例。但在变化检测中，"未变化"像素通常占据绝对多数——毕竟大部分地表在两次拍摄之间并不会发生改变。在LEVIR-CD数据集中，变化区域通常只占总像素的5%到20%。这种极度的类别不平衡给训练带来了巨大挑战：模型可能学到一种"偷懒"策略——把所有像素都预测为"未变化"，就能获得80%以上的准确率，但完全无法检测出真实的变化区域。

最后是变化类型的多样性。本项目中我们关注的是建筑变化，但广义的变化检测还包括植被变化（如森林砍伐或植被恢复）、水体变化（如湖泊萎缩或洪水扩展）、土地覆盖变化（如农田转为建设用地）等。不同类型的变化可能需要不同的检测策略和特征表达。

## 项目架构与数据流

让我们从宏观上了解这个项目的完整架构。整个项目可以被组织为以下几个核心模块：

全局配置模块（Config类）集中管理了所有的超参数和路径设置。这种设计的好处是，你只需要在一个地方修改参数就能影响整个训练流程。其中几个关键参数包括：图像裁剪尺寸256×256、类别数为2（变化/未变化）、批大小为3（因为孪生网络需要同时加载两张图像，显存消耗翻倍）、学习率为0.0001。

数据生成模块（SyntheticChangeDataset）负责生成合成训练数据。它模拟了城市场景中的建筑变化过程：先生成一个包含建筑、道路、植被的随机城市场景作为时相A，然后在此基础上随机添加或移除建筑作为时相B，同时记录变化区域作为标签。

数据加载模块（ChangeDetectionDataset）是一个标准的PyTorch Dataset类，负责从磁盘读取A/B/label三类文件，并进行同步数据增强。所谓"同步增强"，就是对时相A、时相B和标签图做完全相同的几何变换（翻转、旋转），确保三者的空间对应关系不被破坏。

模型模块（SiamUNet及其子模块Encoder、ChangeDecoder）实现了孪生U-Net的完整架构。编码器通过四层卷积逐步提取多尺度特征，解码器通过跳跃连接融合不同尺度的差异信息。

训练引擎（Trainer）管理了完整的训练循环：前向传播计算损失、反向传播更新参数、验证集评估、学习率调度、早停策略等。

可视化模块提供了两种可视化方式：一是变化检测结果的可视化（五列子图：时相A、时相B、真值、预测、叠加），二是训练曲线的可视化（损失曲线和F1曲线）。

整个数据流可以这样描述：原始的双时相影像对经过数据增强后被送入共享编码器，编码器在各层提取的特征被两两做差得到差异特征，差异特征与原始特征拼接后送入解码器，解码器逐层上采样并融合多尺度差异信息，最终输出与输入尺寸相同的变化概率图。训练时，这个概率图与真值标签计算损失并反向传播；推理时，取概率最大的类别作为最终的预测结果。
