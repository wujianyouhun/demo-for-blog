# Attention U-Net——注意力引导的建筑提取

这篇文档将深入剖析本项目使用的核心模型 Attention U-Net 的技术细节。我们将从注意力机制的基本原理讲起，逐行解析关键代码，理解损失函数的设计思路，最终建立起对建筑提取完整技术链条的深入理解。

## 注意力门控的工作原理

在标准 U-Net 中，编码器和解码器之间通过跳跃连接直接传递特征图。解码器在进行上采样恢复空间分辨率后，会将解码器当前层的特征和编码器对应层的特征直接拼接（concatenate）在一起，送入下一层卷积。这种设计虽然保留了丰富的空间细节，但存在一个明显的不足——编码器传递过来的特征图中，所有区域被"平等对待"，无论是建筑区域还是植被、道路等非建筑区域，都获得了同等的重要性。

注意力门控（Attention Gate）正是为了解决这个问题而设计的。它的工作原理可以用一个直观的比喻来理解：假设你是一位城市规划师，正在从空中俯瞰一座城市。你的目光不会均匀地扫过整个画面，而是会自然地聚焦在建筑物上，忽略掉树木、道路等无关信息。注意力门控就是让神经网络也具备这种"选择性聚焦"的能力。

![Attention U-Net 架构中的注意力门控机制](http://crad.ict.ac.cn/fileJSJYJYFZ/journal/article/jsjyjyfz/2023/4/2021-10735-1.jpg)

具体来说，注意力门控接收两个输入信号：一个是从解码器传来的"引导信号"（g），代表网络当前正在关注的目标区域的粗粒度信息；另一个是从编码器跳跃连接传来的"输入特征"（x），包含丰富的空间细节。注意力门控的核心任务是：根据引导信号 g 来判断输入特征 x 中的哪些空间位置是重要的，然后生成一张"注意力地图"（attention map），对重要区域赋予高权重，对无关区域赋予低权重。

这个过程可以用数学公式来表达：

```
attention(x, g) = x * sigmoid(ReLU(W_g(g) + W_x(x)))
```

其中 W_g 和 W_x 是 1×1 卷积操作，用于将两个输入映射到相同的特征空间。ReLU 激活函数引入非线性，sigmoid 函数将输出压缩到 [0, 1] 范围，作为注意力权重。最终，输入特征 x 的每个空间位置都被乘以对应的注意力权重——接近 1 的位置被保留，接近 0 的位置被抑制。

## AttentionGate 类的代码逐行解析

现在让我们逐行阅读本项目中 `AttentionGate` 类的实现代码，理解每个操作的精确含义。

```python
class AttentionGate(nn.Module):
    def __init__(self, g_channels, x_channels, inter_channels):
        super().__init__()
        self.W_g = nn.Sequential(
            nn.Conv2d(g_channels, inter_channels, 1, bias=True),
            nn.BatchNorm2d(inter_channels),
        )
        self.W_x = nn.Sequential(
            nn.Conv2d(x_channels, inter_channels, 1, bias=True),
            nn.BatchNorm2d(inter_channels),
        )
        self.psi = nn.Sequential(
            nn.Conv2d(inter_channels, 1, 1, bias=True),
            nn.BatchNorm2d(1),
            nn.Sigmoid(),
        )
        self.relu = nn.ReLU(inplace=True)
```

初始化函数中定义了三个核心组件。`W_g` 是一个 1×1 卷积层，将来自解码器的引导信号 g 从 `g_channels` 维映射到 `inter_channels` 维。这个降维操作既减少了计算量，又迫使网络学习更有判别力的特征表示。`BatchNorm2d` 层对特征进行归一化处理，稳定训练过程。

`W_x` 也是一个 1×1 卷积层，功能类似，但作用于编码器的跳跃连接特征 x，将其从 `x_channels` 维映射到 `inter_channels` 维。经过这两个变换后，g 和 x 处于同一个特征空间中，可以进行逐元素相加。

`psi` 是最终的注意力权重生成器。它首先通过一个 1×1 卷积将融合后的特征从 `inter_channels` 维压缩到 1 维（即每个空间位置只有一个标量值），然后通过 Sigmoid 激活函数将其映射到 [0, 1] 区间，生成最终的注意力权重图。

```python
    def forward(self, g, x):
        g1 = self.W_g(g)
        x1 = self.W_x(x)

        # 确保空间尺寸匹配
        if g1.shape[2:] != x1.shape[2:]:
            g1 = F.interpolate(g1, size=x1.shape[2:], mode="bilinear", align_corners=True)

        # 注意力权重计算
        attention = self.relu(g1 + x1)
        attention = self.psi(attention)  # (B, 1, H, W) 范围 [0, 1]

        # 用注意力权重加权编码器特征
        return x * attention
```

前向传播函数的执行流程非常清晰。首先分别对引导信号 g 和输入特征 x 进行线性变换。然后检查两者的空间尺寸是否一致——由于上采样和跳跃连接可能引入的微小尺寸差异，这里使用了双线性插值进行对齐。

接下来是关键步骤：将变换后的 g1 和 x1 逐元素相加，然后通过 ReLU 激活函数保留正值、过滤负值。这个加法操作的意义在于：只有当引导信号 g 和输入特征 x 在某个空间位置上"同时认为重要"时，该位置才会产生较大的响应值。

随后，psi 模块将融合特征压缩为单通道的注意力权重图。最后，这个权重图与原始编码器特征 x 相乘（广播机制自动将单通道权重应用到 x 的所有通道上），得到经过注意力加权的特征输出。

## 注意力门控如何帮助聚焦建筑区域

在建筑提取场景中，注意力门控发挥作用的机制可以从不同尺度的特征层级来理解。

在较浅的编码器层（比如 enc1 和 enc2），特征图的空间分辨率较高（128×128 或 64×64），但语义信息较弱。这些层主要捕捉边缘、纹理等底层特征。在这个层级上，注意力门控的引导信号来自解码器的较深层，包含了"哪里有建筑"的粗粒度语义信息。通过这个引导，注意力权重会在建筑边缘区域产生高响应，而在植被纹理、道路纹理等无关区域产生低响应。

在较深的编码器层（比如 enc3 和 enc4），特征图的空间分辨率较低（32×32 或 16×16），但语义信息丰富。这些层能够识别建筑的整体形态、屋顶材质等高层特征。在这个层级上，注意力门控的引导更加精确——它已经能够从粗粒度特征中大致确定建筑的位置和形状，引导编码器特征集中关注这些区域。

综合来看，注意力门控在建筑提取中的核心作用是"抑制非建筑特征的传播"。在标准的 U-Net 中，来自编码器的跳跃连接会将所有特征无差别地传递给解码器，这意味着植被的纹理特征、道路的颜色特征也会被用于最终的建筑预测。而注意力门控通过生成选择性的权重图，相当于为每个跳跃连接安装了一个"过滤器"——只让与建筑相关的特征通过，将无关特征衰减到接近零。

这种机制对于提升建筑边界精度尤为重要。在建筑边界处，建筑像素和非建筑像素相邻，特征变化剧烈。注意力门控能够精准地在边界处产生从高到低的权重过渡，帮助模型更好地学习边界的精确位置。

## AttentionUNet 完整架构流程

有了注意力门控这个关键组件，我们再来看完整的 Attention U-Net 架构是如何组织的。

![U-Net 编码器-解码器结构与跳跃连接示意](http://gips0.baidu.com/it/u=4078143806,3955642015&fm=3074&app=3074&f=JPEG?w=1553&h=1999&type=normal&func=T)

```python
class AttentionUNet(nn.Module):
    def __init__(self, in_channels=3, num_classes=2):
        super().__init__()

        # 编码器
        self.enc1 = ConvBlock(in_channels, 64)
        self.enc2 = ConvBlock(64, 128)
        self.enc3 = ConvBlock(128, 256)
        self.enc4 = ConvBlock(256, 512)
        self.pool = nn.MaxPool2d(2)

        # 瓶颈层
        self.bottleneck = ConvBlock(512, 1024)

        # 上采样
        self.up4 = nn.Upsample(scale_factor=2, mode="bilinear", align_corners=True)

        # 注意力门控
        self.ag4 = AttentionGate(g_channels=1024, x_channels=512, inter_channels=256)

        # 解码器
        self.dec4 = ConvBlock(1024 + 512, 512)

        # 分类输出
        self.final = nn.Conv2d(64, num_classes, kernel_size=1)
```

整个网络呈现出清晰的 U 型结构。输入图像首先通过四层编码器，每层由一个 `ConvBlock`（两次 3×3 卷积 + BatchNorm + ReLU）和一个 2×2 最大池化组成。每经过一次池化，特征图的空间尺寸减半，通道数翻倍。从输入到编码器第四层，特征图的变化路径是：

```
输入 (3, 256, 256) → Enc1 (64, 256, 256) → Pool → Enc2 (128, 128, 128)
→ Pool → Enc3 (256, 64, 64) → Pool → Enc4 (512, 32, 32) → Pool → Bottleneck (1024, 16, 16)
```

瓶颈层输出的是最抽象的全局语义特征，包含了"图像中大概有哪些类型的物体"的信息，但空间分辨率已经很低。

解码器路径是编码器的镜像过程。每个解码器阶段首先通过双线性上采样将特征图放大两倍，然后将上采样后的特征与经过注意力门控加权的编码器特征拼接在一起，最后通过 ConvBlock 进行特征融合。解码过程的关键创新在于注意力门控的位置——它嵌入在每一条跳跃连接上，对编码器特征进行选择性过滤。

```python
    def forward(self, x):
        # 编码
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        e4 = self.enc4(self.pool(e3))
        b = self.bottleneck(self.pool(e4))

        # 解码 + 注意力门控
        d4 = self.up4(b)
        e4_attn = self.ag4(g=d4, x=e4)
        d4 = self.dec4(torch.cat([d4, e4_attn], dim=1))
        # ... 依次类推到 dec1

        return self.final(d1)
```

以 dec4 阶段为例：瓶颈层输出 b 经过上采样后得到 d4（通道数 1024，空间尺寸 32×32）。然后将 d4 作为引导信号、编码器的 e4 作为输入特征，送入注意力门控 ag4。ag4 输出的 e4_attn 是经过注意力加权的编码器特征（通道数 512，空间尺寸 32×32）。最后将 d4 和 e4_attn 在通道维度拼接（总通道数 1024+512=1536），送入解码器卷积块 dec4 进行融合。

最终，解码器最后一层 dec1 的输出通过一个 1×1 卷积映射到 2 个通道（对应建筑和非建筑两个类别），得到与输入等大的分割预测图。

## BuildingLoss 损失函数设计

损失函数是训练过程中指导模型学习方向的关键信号。本项目使用了一个精心设计的组合损失函数 `BuildingLoss`，结合了 BCE Loss 和 Dice Loss 两种互补的损失形式。

```python
class BuildingLoss(nn.Module):
    def __init__(self, pos_weight=3.0):
        super().__init__()
        self.bce = nn.BCEWithLogitsLoss(
            pos_weight=torch.tensor([pos_weight])
        )

    def forward(self, pred, target):
        # BCE Loss
        pred_building = pred[:, 1:2, :, :]
        target_float = target.unsqueeze(1).float()
        bce_loss = self.bce(pred_building, target_float)

        # Dice Loss
        pred_prob = F.softmax(pred, dim=1)[:, 1]
        target_bin = target.float()
        inter = (pred_prob * target_bin).sum()
        union = pred_prob.sum() + target_bin.sum()
        dice_loss = 1 - (2 * inter + 1) / (union + 1)

        return bce_loss + dice_loss
```

BCE Loss（Binary Cross Entropy）是像素级的二分类损失。它对每个像素独立计算分类损失，然后取平均。BCE Loss 的优点是梯度稳定、收敛速度快，但缺点是容易受到类别不平衡的影响——在建筑提取中，建筑像素通常只占图像面积的 10% 到 30%，如果简单地使用 BCE Loss，模型可能倾向于将所有像素预测为非建筑来获得较高的整体准确率。

为了解决这个问题，代码中使用了 `pos_weight=3.0` 参数。这意味着模型在计算建筑像素（正样本）的损失时，会将其权重放大 3 倍。这样做相当于告诉模型："漏检一个建筑像素的代价是误检一个非建筑像素的三倍"，从而促使模型更加积极地检测建筑区域。

Dice Loss 是区域级的损失函数，直接优化预测区域与真值区域之间的重叠度。Dice 系数定义为：

```
Dice = 2 × |预测 ∩ 真值| / (|预测| + |真值|)
```

Dice Loss 对类别不平衡天然具有鲁棒性，因为它的计算不依赖于真负样本（True Negative）的数量。在建筑提取中，即使建筑面积只占 10%，Dice Loss 仍然能够准确地度量建筑区域的匹配程度。代码中的 "+1" 是平滑项，防止分母为零的情况。

将 BCE Loss 和 Dice Loss 相加作为总损失，能够同时获得两者的优势——BCE Loss 提供稳定的像素级梯度信号，Dice Loss 关注区域级的重叠优化。这种组合策略在医学影像分割和遥感建筑提取中都被证明是有效的。

## 建筑提取的评价指标

本项目实现了全面的建筑提取评价指标体系，包括 F1 Score、IoU、Overall Accuracy、Precision 和 Recall。

```python
def compute_building_metrics(pred, target):
    pred_bin = pred.argmax(dim=1)

    tp = ((pred_bin == 1) & (target == 1)).sum().float()
    fp = ((pred_bin == 1) & (target == 0)).sum().float()
    fn = ((pred_bin == 0) & (target == 1)).sum().float()
    tn = ((pred_bin == 0) & (target == 0)).sum().float()

    precision = tp / (tp + fp + 1e-8)
    recall = tp / (tp + fn + 1e-8)
    f1 = 2 * precision * recall / (precision + recall + 1e-8)
    iou = tp / (tp + fp + fn + 1e-8)
    oa = (tp + tn) / (tp + fp + fn + tn + 1e-8)

    return {"F1": f1.item(), "IoU": iou.item(), "OA": oa.item(),
            "Precision": precision.item(), "Recall": recall.item()}
```

F1 Score 是 Precision 和 Recall 的调和平均数，是建筑提取中最核心的评价指标。它综合衡量了模型"找得准"（Precision）和"找得全"（Recall）的能力。F1 为 1 表示完美预测，为 0 表示最差预测。在建筑提取的实际应用中，F1 达到 0.85 以上通常被认为是很好的结果。

IoU（Intersection over Union）衡量的是预测建筑区域与真实建筑区域之间的重叠程度。它的计算公式是"交集面积除以并集面积"。IoU 对预测的偏差非常敏感——即使预测的建筑轮廓与真值只差几个像素的边界，IoU 也会有明显的下降。因此 IoU 特别适合评价建筑边界精度。

Precision（精确率）反映的是"模型预测为建筑的像素中，有多少确实是建筑"。高 Precision 意味着模型的误检率低——被标记为建筑的区域基本可靠。在城市规划等应用中，高 Precision 可以避免将道路、广场等非建筑区域错误地统计为建筑面积。

Recall（召回率）反映的是"实际的建筑像素中，有多少被模型成功检测到了"。高 Recall 意味着模型的漏检率低——大多数真实建筑都被成功识别。在违建检测等应用中，高 Recall 尤为重要——你不想漏掉任何一栋可能存在的违法建筑。

OA（Overall Accuracy）是整体准确率，表示所有像素中被正确分类的比例。在建筑提取中，由于非建筑像素占多数，即使模型将所有像素都预测为非建筑，OA 也可能达到 70% 到 80%。因此 OA 不是一个敏感的评价指标，F1 和 IoU 更能反映模型的真实水平。

## 矢量导出：从栅格预测到 GeoJSON 多边形

模型的原始输出是每个像素属于建筑或非建筑的概率图，这是一种栅格数据。但在 GIS 应用中，我们通常需要矢量格式的建筑轮廓数据。`export_building_vector` 函数实现了这个转换过程。

矢量导出的核心是使用 rasterio 库的 `features.shapes` 函数。这个函数扫描二值栅格图像，将连通的建筑像素区域提取为多边形几何对象。每个多边形由一系列坐标点定义，描述了建筑轮廓的边界。

```python
# 模拟地理变换（实际使用时替换为真实地理坐标）
transform = from_bounds(108.9, 34.2, 109.0, 34.3, pred.shape[1], pred.shape[0])

# 提取多边形
for geom, value in features.shapes(pred, transform=transform):
    if value == 1:  # 建筑
        all_polygons.append({
            "type": "Feature",
            "geometry": geom,
            "properties": {"class": "building", "source": f"sample_{i}"}
        })
```

`from_bounds` 函数定义了像素坐标到地理坐标的映射关系。在演示代码中，使用了模拟的经纬度范围（108.9°E 到 109.0°E，34.2°N 到 34.3°N），实际应用中应替换为航空影像的真实地理范围信息。

提取出的多边形被组装为标准 GeoJSON 格式，这是一种广泛使用的地理数据交换格式。每个建筑多边形包含几何信息（坐标点序列）和属性信息（类别标签、来源样本编号），可以直接导入各种 GIS 软件进行后续的空间分析和可视化。

## 合成数据中的建筑形状模拟

本项目的合成数据生成器在 `_make_building_mask` 函数中实现了三种建筑形状的模拟：矩形、L 型和十字型。这三种形状覆盖了现实世界中最常见的建筑平面形态。

矩形建筑对应的是普通住宅、仓库等简单形态的建筑。L 型建筑模拟的是带有侧翼或转角结构的建筑。十字型建筑则代表了更加复杂的商业或公共建筑形态。生成器在每个样本中随机放置 3 到 12 个不同形状和大小的建筑，创造丰富的训练样本多样性。

阴影效果的模拟也是合成数据的一个亮点。代码通过在建筑的右下方添加暗色区域来模拟太阳角度造成的建筑投影：

```python
# 添加阴影（建筑右下方）
shadow_mask = np.zeros((h, w), dtype=bool)
shift_x = random.randint(3, 8)
shift_y = random.randint(3, 8)
if shift_y < h and shift_x < w:
    shifted = np.zeros_like(bldg_mask)
    shifted[shift_y:, shift_x:] = bldg_mask[:-shift_y, :-shift_x]
    shadow_mask = shifted & ~bldg_mask
    image[shadow_mask] *= random.uniform(0.6, 0.8)
```

这段代码将建筑掩膜向右下方平移若干像素，得到"阴影区域"（排除建筑本身占据的区域），然后将阴影区域的像素值乘以 0.6 到 0.8 的随机系数，模拟阴影使地面变暗的效果。这种阴影模拟帮助模型学习区分"建筑本身"和"建筑投射的阴影"，避免在实际推理中将阴影误判为建筑。

背景生成同样精心设计。`_make_background` 函数模拟了植被（绿色基调加随机噪声）、裸地（棕色调矩形区域）和道路（灰色水平或垂直条带）三种典型的城市地物，为建筑提取任务提供了丰富的干扰背景。
