# 多分类 U-Net 样本制作使用手册

本流程将 `Unet/Data/裁剪.tif` 和 `Unet/Data/shp/polygon_rg.shp` 转换为一对一的影像样本与标签样本。它适用于道路、居民地、耕地、裸地、光伏场五类地物的语义分割。

## 开始前：矢量属性和拓扑检查

在 ArcGIS / QGIS 中打开 `polygon_rg.shp`，新增整数型字段 `class_id`，按下表赋值。不要使用 FID，也不要只使用中文类别字段 `LB` 进行栅格化。

| class_id | 类别 |
|---:|---|
| 1 | 道路 |
| 2 | 居民地 / 建成区 |
| 3 | 耕地 |
| 4 | 裸地 |
| 5 | 光伏场 |
| 255 | 不确定区域，可选 |

当前样本若已经使用 `1–5` 编码，脚本默认会在内存中自动转换为上述 `0–4` 编码，原始 Shapefile 不会被修改。输出裁切矢量会保留 `source_class_id` 字段，以便核对原始编码。

完成后检查：

- 所有面都有 `class_id`；
- 几何无自相交、空面和重叠面；道路必须有可见宽度；
- 矢量与影像的坐标位置一致；
- 村庄模糊边界和难以判别的像元不强制赋类，可留为 `255`；
- 道路与其他面重叠时，先在 GIS 中消除重叠。推荐优先级为：道路 > 光伏场 > 居民地 > 耕地 > 裸地。

## 安装依赖

建议使用当前 Conda 环境安装地理数据依赖：

```powershell
conda activate python12
conda install -c conda-forge geopandas pyogrio rasterio
pip install numpy
```

也可使用 `Unet/requirements.txt`，但 Windows 上 GeoPandas 及其 GDAL 依赖通常使用 Conda 安装更稳定。

## 运行

在仓库根目录执行：

```powershell
conda activate python12
python Unet/prepare_multiclass_samples.py
```

默认读取：

```text
Unet/Data/裁剪.tif
Unet/Data/shp/polygon_rg.shp
```

脚本会先把影像统一为 `EPSG:3857`、`10 m × 10 m` 像元，并保存为输出目录中的 `source_EPSG_3857_10m.tif`。后续的格网、影像样本、矢量裁切和标签栅格化全部以这幅统一影像为模板。原始 `裁剪.tif` 当前虽为 EPSG:3857，但像元大小约为 12.93 米，因此仍会被重采样至 10 米。

默认输出：

```text
Unet/dataset/qilian_multiclass_5class/
```

如果修改过分类字段或需要覆盖已生成成果：

```powershell
python Unet/prepare_multiclass_samples.py --class-field class_id --overwrite
```

自动重编码是默认行为。若原矢量已使用 `0–4`，脚本会保持不变；如需指定其他映射，可使用：

```powershell
python Unet/prepare_multiclass_samples.py --class-remap "1:0,2:1,3:2,4:3,5:4" --overwrite
```

## 脚本实际执行的顺序

```text
读取原始影像与分类面
  ↓
检查 class_id、空几何、无效几何和 CRS
  ↓
统一为 EPSG:3857、10 m 像元影像
  ↓
按统一影像像元网格建立 256×256 样本网格
  ↓
按连续列划分 train / val / test，避免相邻样本泄漏
  ↓
按每个网格裁切影像与矢量面
  ↓
以影像块的 CRS、范围、仿射变换、256×256 像元网格为模板栅格化矢量
  ↓
输出 image.tif、mask.tif、裁切矢量、格网和样本清单
```

原图边缘不足 256 像元的部分会在影像中填充 NoData/0，在标签中写为 `255=ignore`。因此所有样本严格为 `256×256`，但填充区域不会参与后续训练。10 米分辨率下，一个样本块实际覆盖 `2.56 km × 2.56 km`。

## 输出结构

```text
Unet/dataset/qilian_multiclass_5class/
  sample_grid.gpkg                    # 格网及 train/val/test 字段
  source_EPSG_3857_10m.tif            # 统一坐标系、分辨率后的样本模板
  manifest.csv                         # 每个样本的对应关系
  train/
    images/r000_c000.tif
    masks/r000_c000_mask.tif
    vectors/r000_c000.gpkg
  val/
    images/
    masks/
    vectors/
  test/
    images/
    masks/
    vectors/
```

每一对同名文件是严格对齐的：

```text
train/images/r000_c000.tif
train/masks/r000_c000_mask.tif
```

影像保持原始的 4 个波段；标签为 1 个 `uint8` 波段，其中 `1–5` 是地物类别，`255` 是 ignore。

## 完成后的检查

用 QGIS 加载任意 `images/*.tif` 与对应 `masks/*_mask.tif`，将 mask 设为分类渲染。逐项确认：

1. 标签边界与影像中的道路、建成区、耕地、裸地、光伏场对齐；
2. 标签中存在预期的类别值；
3. 边缘填充区值为 255；
4. `sample_grid.gpkg` 中 train、val、test 位于相互分离的空间列；
5. 每个集合至少包含主要类别。若验证集或测试集缺少某类，应调整研究区或补充该类样本后再训练。

当前 `裁剪.tif` 尺寸为 728×581 像元，生成 3×3 共 9 个样本块。它足以验证流程，但不足以支撑六模型正式对比；需在更大且彼此分离的区域继续制作样本。
