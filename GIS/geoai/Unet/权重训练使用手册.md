# 五分类 U-Net 权重训练使用手册

本脚本使用已生成的 `Unet/dataset/qilian_multiclass_5class` 样本，依次训练六种 U-Net 变体并生成 `.pth` 权重。

## 数据与类别

输入影像为 4 波段、EPSG:3857、10 米分辨率的 256×256 样本；标签值为：

```text
0 = 道路
1 = 居民地 / 建成区
2 = 耕地
3 = 裸地
4 = 光伏场
255 = ignore，不参与训练和精度计算
```

训练脚本自动使用 `in_channels=4`、`num_classes=5`、`ignore_index=255`。

## 先跑通流程

当前仅有 6 个训练块和 3 个验证块，适合生成流程验证权重。使用较小网络、3 轮训练：

```powershell
conda activate python12
python Unet/train_multiclass_models.py --epochs 3 --base-channels 8 --batch-size 1 --device cpu
```

这会依次训练 U-Net、ResUNet、Attention U-Net、U-Net++、TransUNet、Swin-UNet，并保存：

```text
models/Unet/qilian_multiclass_5class/
  unet/best.pth
  resunet/best.pth
  attention_unet/best.pth
  unetpp/best.pth
  transunet/best.pth
  swin_unet/best.pth
  training_summary.json
```

## 正式训练建议

样本扩充并检查类别覆盖后，可使用：

```powershell
python Unet/train_multiclass_models.py --epochs 50 --base-channels 16 --batch-size 2 --device cuda
```

六模型比较时，请确保每个模型使用完全相同的 train / val / test 样本、类别、增强、轮数和随机种子。模型选择依据为验证集 `val_mIoU`；测试集只在权重确定后进行一次最终评价。

当前测试集中没有光伏场，不应据此报告光伏场的最终精度。流程试跑后，应补充含光伏场的独立测试样本。
