# 五分类整图推理使用手册

六个入口脚本默认读取 `Unet/Data/Qilian.tif`，加载对应五分类权重，统一到 EPSG:3857、10 米分辨率，再以 256×256 滑窗预测。

```powershell
conda activate python12
python Unet/resunet_example.py --device cpu
```

从 `Unet` 目录执行时，应去掉 `Unet/`：

```powershell
python .\resunet_example.py --device cpu
```

可选模型：

```text
unet_example.py
resunet_example.py
attention_unet_example.py
unetpp_example.py
transunet_example.py
swin_unet_example.py
```

当前改进版权重位于：

```text
models/Unet/qilian_multiclass_5class_refined/<模型>/best.pth
```

五分类输出位于：

```text
Unet/out/qilian_multiclass_5class_refined/<模型>/
  classification.tif
  probability_0_road.tif
  probability_1_built_up.tif
  probability_2_cropland.tif
  probability_3_bare_land.tif
  probability_4_solar_farm.tif
  inference_report.json
```

`classification.tif` 的值为：0=道路、1=居民地、2=耕地、3=裸地、4=光伏场。各概率 TIFF 的值范围为 0–1。

## 派生建筑和植被/耕地结果

建筑提取：

```powershell
python Unet/resunet_example.py --task building --device cpu
```

输出：

```text
Unet/out/qilian_multiclass_5class_refined/resunet/building/
  building_mask.tif
  building_probability.tif
```

植被/耕地提取：

```powershell
python Unet/resunet_example.py --task vegetation --device cpu
```

输出：

```text
Unet/out/qilian_multiclass_5class_refined/resunet/vegetation/
  vegetation_mask.tif
  vegetation_probability.tif
```

当前没有单独训练“自然植被”类别，`vegetation` 暂时等同于 `cropland / 耕地`。二值掩膜均为 `0=背景、1=目标`，并保留 EPSG:3857、10 米像元网格。

## 可用参数示例

```powershell
python Unet/resunet_example.py --device cpu --overwrite
python Unet/transunet_example.py --device cuda --stride 256 --overwrite
python Unet/unetpp_example.py --input Unet/Data/裁剪.tif --output-dir Unet/out/crop_unetpp --overwrite
```

当前样本量仍然较小，结果适合流程验证和模型对比展示；若要正式精度成果，需要继续扩充样本并重新训练。
