# U-Net 系列推理启动说明

当前项目使用的是五分类语义分割流程，不再使用早期的 `模型_building.pth`、`模型_vegetation.pth` 二分类权重。

## 数据与权重

默认推理影像：

```text
Unet/Data/Qilian.tif
```

默认权重目录：

```text
models/Unet/qilian_multiclass_5class_refined/<模型>/best.pth
```

支持的模型入口：

```text
unet_example.py
resunet_example.py
attention_unet_example.py
unetpp_example.py
transunet_example.py
swin_unet_example.py
```

五分类类别为：

```text
0 道路 road
1 居民地 built_up
2 耕地 cropland
3 裸地 bare_land
4 光伏场 solar_farm
```

## 五分类推理

从仓库根目录执行：

```powershell
conda activate python12
python Unet/resunet_example.py --device cpu
```

从 `Unet` 目录执行时去掉前面的 `Unet/`：

```powershell
python .\resunet_example.py --device cpu
```

五分类结果输出到：

```text
Unet/out/qilian_multiclass_5class_refined/<模型>/
```

主要文件包括：

```text
classification.tif
probability_0_road.tif
probability_1_built_up.tif
probability_2_cropland.tif
probability_3_bare_land.tif
probability_4_solar_farm.tif
inference_report.json
```

## 建筑与植被/耕地提取

建筑提取命令：

```powershell
python Unet/resunet_example.py --task building --device cpu
```

输出到：

```text
Unet/out/qilian_multiclass_5class_refined/resunet/building/
  building_mask.tif
  building_probability.tif
```

植被/耕地提取命令：

```powershell
python Unet/resunet_example.py --task vegetation --device cpu
```

输出到：

```text
Unet/out/qilian_multiclass_5class_refined/resunet/vegetation/
  vegetation_mask.tif
  vegetation_probability.tif
```

注意：当前训练样本没有单独的“自然植被”类别，`--task vegetation` 目前映射到 `cropland / 耕地`。如果要提取真正植被，需要在样本中新增植被类别并重新训练权重。

## 常用参数

覆盖已有输出：

```powershell
python Unet/resunet_example.py --task building --device cpu --overwrite
```

指定其他输入影像或输出目录：

```powershell
python Unet/resunet_example.py --input Unet/Data/Qilian.tif --output-dir Unet/out/test_resunet --device cpu --overwrite
```

脚本默认使用 256×256 滑窗、192 像素步长、EPSG:3857、10 米分辨率。
