# U-Net 系列批量推理启动说明

## 已识别的数据

当前 `Unet/DATA` 中已有两幅待推理影像：`Xian.tif`（西安）和 `Qilian.tif`（祁连）。Windows 不区分 `DATA` 与 `data` 的大小写，因此脚本默认路径 `Unet/data` 可直接读取这两幅影像，无须移动或改名。

## 模型准备（必须）

每个模型、每个任务均需要自己的二分类分割 checkpoint。请将模型放在仓库的 `models/Unet` 下，并严格使用下列名称：

```text
models/Unet/
  unet_building.pth
  unet_vegetation.pth
  resunet_building.pth
  resunet_vegetation.pth
  attention_unet_building.pth
  attention_unet_vegetation.pth
  unetpp_building.pth
  unetpp_vegetation.pth
  transunet_building.pth
  transunet_vegetation.pth
  swin_unet_building.pth
  swin_unet_vegetation.pth
```

checkpoint 必须由本项目的相同模型结构训练并保存，内容含 `model`、`task`、`bands`、`base` 与 `state_dict`。目前仓库中只有另一项目的六分类 U-Net/U-Net++ 权重，和此处的二分类五模型结构不兼容，不能直接复制使用。

若本地没有模型，可在启动时提供下载链接。脚本会先检查本地文件，仅在缺失时下载；可选 SHA256 校验可防止下载损坏。

## 启动

从仓库根目录执行。默认同时输出建筑、植被两类结果，数据读取自 `Unet/data`，结果写入 `Unet/out/<模型>/<任务>/`。

```powershell
python Unet/unet_example.py
python Unet/resunet_example.py
python Unet/attention_unet_example.py
python Unet/unetpp_example.py
python Unet/transunet_example.py
python Unet/swin_unet_example.py
```

只处理建筑或植被：

```powershell
python Unet/resunet_example.py --task building
python Unet/resunet_example.py --task vegetation
```

模型不存在时下载并运行：

```powershell
python Unet/swin_unet_example.py --building-weights-url "https://example.com/swin_unet_building.pth" --vegetation-weights-url "https://example.com/swin_unet_vegetation.pth"
```

## 输出与参数

每张输入影像生成两个文件：`*_mask.tif` 为二值掩膜（0=背景、1=目标），`*_mask_probability.tif` 为 0–1 的预测概率；投影、范围、分辨率和像元对齐均继承输入影像。每个模型目录另有 `inference_report.json`。

各入口脚本的 `main()` 中集中设置了默认参数：`data` 路径、`out` 路径、任务、512×512 切片、384 像素步长、0.50 阈值和自动设备选择。通常只需编辑对应脚本 `main()` 内的这一段；命令行参数可临时覆盖，例如：

```powershell
python Unet/transunet_example.py --tile-size 256 --stride 192 --threshold 0.60 --device cuda
```

需要安装：`torch`、`rasterio`、`numpy`。Transformer 模型（TransUNet、Swin-UNet）推荐 CUDA；显存不足时将 `tile-size` 改为 256。
