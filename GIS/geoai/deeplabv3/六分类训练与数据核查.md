## 波段与缩放假设

原图没有波段名称描述：颜色解释为 gray / undefined，不能从元数据确定 RGB 顺序或辐射定标公式。当前初版采用 **1、2、3 波段作为 RGB，scale=10000**。预览的颜色看起来合理，但仍应结合原始产品说明确认；这些设置已记录在 dataset.json 和 checkpoint 中。

训练和推理使用 `clip(image / 10000, 0, 1)` 后的 ImageNet 归一化。预览图采用独立的 2%–98% 拉伸，仅用于查看，不会写入训练影像。第 4 波段目前保留在切片文件中，但不送入三通道网络。

原图不重投影、不降低分辨率，标签直接栅格化到各自影像的像元网格，保留原始 CRS 和仿射变换。EPSG:4326 的像元单位是度，不能将它直接解释为米。

## 切片与验证划分

生成目录：`deeplabv3/data/landcover_6class/`。

```text
landcover_6class/
  dataset.json                # 类别、波段、scale、核查信息和切片 manifest
  full_masks/
    image1_mask.tif
    image2_mask.tif
  train/
    images/*.tif
    masks/*_mask.tif
  val/
    images/*.tif
    masks/*_mask.tif
```

切片为 256×256，边缘不足的标签补 255，影像补 0。保留类别 0，不将它设置为标签 NoData。

每幅影像取从 0 开始的第 1 列作为验证条带（原图 x=256..511），其余列训练。这样 image1 的水体和 image2 的光伏在训练和验证中都有像元。共 **48 个训练切片、9 个验证切片**，无训练 / 验证像元重叠。

| 类别 | 训练有效像元 | 验证有效像元 |
|---|---:|---:|
| 道路 | 20,990 | 3,667 |
| 建设用地 / 居民地 | 116,264 | 32,152 |
| 耕地 | 1,083,068 | 324,514 |
| 裸地 | 1,303,907 | 112,796 |
| 水体 | 15,701 | 1,573 |
| 光伏 | 19,867 | 14,947 |

当前只有两块区域，验证条带与训练区域相邻，**验证指标属于初步结果，不是独立区域的泛化精度**。水体只来自 image1，光伏只来自 image2；后续应补充这两类在其他区域、季节及成像条件下的样本，并预留独立测试区。

## 复现核查和样本制作

建议使用现有 `python12` 环境，在项目根目录运行：

```powershell
conda activate python12
python -m pip install -r deeplabv3/requirements.txt

# 只核查，不生成样本。
python deeplabv3/prepare_training_data.py --inspect-only

# 生成样本；为避免覆盖，目标目录需为空或不存在。
python deeplabv3/prepare_training_data.py
```

若默认样本目录已生成，重新制作时指定新目录：

```powershell
python deeplabv3/prepare_training_data.py --output-dir deeplabv3/data/landcover_6class_v2
```

核查报告及预览位于 `deeplabv3/out/training_data_review/`。完整源编号映射、每类像元数、覆盖率、影像值域和切片归属保存在 `inspection.json` / `dataset.json` 中。

## 首版 checkpoint 训练

```powershell
python deeplabv3/train_remote_sensing.py --dataset-dir deeplabv3/data/landcover_6class --epochs 5 --batch-size 2 --device cpu --class-weighting inverse-sqrt --checkpoint models/deeplabv3/landcover_6class_best.pth
```

训练脚本自动读取该数据集的 `dataset.json`，获得六类名称、波段、scale 和切片大小，避免误用合成数据的三分类默认参数。显式指定命令行参数时，以命令行参数为准。

本次采用官方 COCO/VOC DeepLabV3-ResNet50 参数初始化，重新初始化最终分类层，学习率 1e-4，随机种子 42，冻结 BatchNorm 运行统计量。训练集中耕地、裸地较多，因此按训练有效像元数量的平方根倒数设置交叉熵类别权重，缓解类别不平衡；验证统计仍根据未加权的混淆矩阵计算。

每轮保存训练损失、验证损失、验证 mIoU、逐类 IoU 和混淆矩阵。mIoU 提升时更新最佳 checkpoint：

```text
models/deeplabv3/landcover_6class_best.pth
models/deeplabv3/landcover_6class_best.history.json
```

5 个 epoch 用于生成和检查初版权重，不能仅凭完成训练就认定模型已满足实际生产精度。请查看逐类 IoU，尤其是道路、水体、光伏，而不是只看平均值。重复训练不会覆盖已有 checkpoint，需改名或明确传入 `--overwrite`。当前 checkpoint 用于推理，不保存优化器状态，不能用它无损恢复原训练进度。

## 使用 checkpoint 推理

```powershell
python deeplabv3/remote_sensing_inference.py --image deeplabv3/data/train/image2.tif --checkpoint models/deeplabv3/landcover_6class_best.pth --tile-size 256 --halo 32 --output deeplabv3/out/landcover_6class/image2_classification.tif
```

推理会从 checkpoint 读取六类名称、RGB 波段和 scale，输出类别 0–5，NoData 为 255，并保留影像坐标信息。对参与训练的 image1 / image2 推理主要用于检查输出与标注的位置及表现，不能当成独立测试。

## 验证脚本

```powershell
python deeplabv3/test_workflow.py
```

## 本次 5 轮训练的实际结果

训练已完成，最佳 checkpoint 来自 **第 4 轮**，验证 mIoU 为 **0.215706**。第 5 轮分数回落到 0.159247，因此保留第 4 轮，而不是最后一轮。

| 轮次 | 训练损失 | 验证损失 | 验证 mIoU |
|---|---:|---:|---:|
| 1 | 1.377688 | 1.542590 | 0.094464 |
| 2 | 1.357978 | 1.366329 | 0.206441 |
| 3 | 1.075350 | 1.319372 | 0.210522 |
| 4 | 0.975979 | 1.286139 | 0.215706 |
| 5 | 0.851803 | 1.632345 | 0.159247 |

最佳轮次的逐类 IoU：

| 类别 | 验证 IoU |
|---|---:|
| 道路 | 0.000000 |
| 建设用地/居民地 | 0.000000 |
| 耕地 | 0.740595 |
| 裸地 | 0.553641 |
| 水体 | 0.000000 |
| 光伏 | 0.000000 |

**当前仅耕地和裸地得到有效 IoU，道路、建设用地/居民地、水体、光伏的验证 IoU 均为 0。这份 checkpoint 用于首版流程检查，尚不能作为可靠的六类识别模型。** 第 5 轮训练损失继续下降而验证表现变差，也说明不能只看训练损失、或简单认定增加轮次必然提高效果。后续需要更多区域的少数类样本、标注语义复核，以及更充分的训练和验证调参。

实际权重：`models/deeplabv3/landcover_6class_best.pth`。模型加载、六通道前向推理、最佳轮次选择、验证像元数和 GeoTIFF 坐标信息检查均已通过。训练摘要与 SHA256 见同目录 `landcover_6class_best.summary.json`。
