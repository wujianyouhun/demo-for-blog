# DeepLabV3 遥感分类效果诊断与优化指南

## 目前的问题是什么

当前 `landcover_6class_best.pth` 是五轮试训练的产物，最佳参数来自第 4 轮，验证 mIoU 为 0.215706。验证混淆矩阵显示，模型将所有有效像元预测成了耕地或裸地：道路、建设用地、水体、光伏没有任何预测像元。问题首先是少数类尚未学会，不能只靠平滑、改配色或导出矢量解决。

| 类别 | 训练像元 | 验证 IoU |
|---|---:|---:|
| 道路 | 20,990 | 0.0000 |
| 建设用地/居民地 | 116,264 | 0.0000 |
| 耕地 | 1,083,068 | 0.7406 |
| 裸地 | 1,303,907 | 0.5536 |
| 水体 | 15,701 | 0.0000 |
| 光伏 | 19,867 | 0.0000 |

耕地和裸地合计占训练有效像元约 93.25%。即使损失下降，网络也可能长期只输出大类。因此必须同时检查逐类召回率、预测像元占比和混淆矩阵，不能只看总体准确率或训练损失。本次新评估已复现原模型 mIoU；总体准确率为 77.77%，仍掩盖了四类完全缺失的问题。

## 为什么目前不能直接下结论说 DeepLabV3 不如 U-Net

本次读取了两个目录下实际保存的训练历史。U-Net 系列的三轮试运行同样表现较差；效果较好的版本经过了 80 轮训练。

| 本地模型 | 训练轮数 | 最佳验证 mIoU | 最佳轮次 |
|---|---:|---:|---:|
| DeepLabV3 六分类 | 5 | 0.2157 | 4 |
| ResUNet refined 五分类 | 80 | 0.4525 | 49 |
| U-Net++ refined 五分类 | 80 | 0.4866 | 50 |
| TransUNet refined 五分类 | 80 | 0.5017 | 31 |
| Swin-UNet refined 五分类 | 80 | 0.4579 | 34 |

这张表记录各自实验，**不是公平的架构排行榜**。DeepLabV3 使用 image1/image2 六类样本，包括水体；U-Net 现有训练集是五类，不包含水体。前者使用三个波段、固定除以 10000 再做 ImageNet 归一化；后者使用四个波段、逐切片各波段 p99 归一化。U-Net 还将样本处理为 EPSG:3857、10 个投影坐标单位的像元，而 DeepLabV3 保持原始网格。

还要区分 epoch 与更新次数：DeepLabV3 的训练/验证切片为 48/9，U-Net 现有样本为 6/3，另有 3 个 test 切片。在 batch size=2、每轮全部训练样本的条件下，五轮 DeepLabV3 约 120 次参数更新，80 轮 U-Net 约 240 次。因此不能把 80/5 直接理解成 16 倍有效训练预算，更不能仅据此解释全部差距。输入像元曝光、参数量、采样与实际时间也应记录。

公平比较应统一样本、标签语义、空间划分、波段、预处理、训练预算与评价代码，再分别训练。可以让 DeepLabV3 读取 U-Net 的现有五类 train/val/test 切片作对照，但不能把六类权重直接当成五类权重加载，也不能删除水体后未经重新评估就比较均值。

## 先检查数据，再调整网络

### 类别语义与边界质量

image1 的原编号 5 是水体，image2 的原编号 5 是光伏，必须继续使用按名称统一后的编号。道路为 0，未标注为 255，不能把道路设成 NoData。检查居民地是整体地块还是屋顶，光伏是面板还是整个场区；语义口径必须一致。

人工复核道路两侧边界、阴影、水岸、光伏与裸地交界。几何拓扑正确不代表解译正确，零冲突像元也不证明矢量不存在亚像元重叠。将标签叠加到原始影像，而不只是查看彩色标签本身。

### 波段与辐射预处理

当前源影像缺少波段名称。1、2、3 为 RGB、scale=10000 是已有假设，不能从 uint16 或四波段文件推断出来。确认产品说明中的顺序、比例和偏移；训练与推理必须使用相同处理。

第四波段只有在确认含义后才值得作为光谱输入实验。如果是近红外，可能帮助区分植被、水体与人造地物；若含义未知，不应擅自称为 NIR。增加波段需要改网络第一层并重新训练，已有三通道权重不能直接接收四通道影像。

逐切片 p99 可以提升局部对比，但相同地物会随窗口内容得到不同数值，同一位置在不同窗口中的归一化也可能不同。不要仅为了复制 U-Net 配置而混用其预处理。建议先保留固定缩放做可重复基线，再单独比较按训练集统计拟合的缩放；统计量只能从训练集拟合。

### 空间尺度与划分

影像 CRS 不同不会直接导致网络分类错误，但像元对应地面尺寸不同会改变道路宽度等特征。EPSG:3857 的 10 个投影单位不等于所有纬度都精确的 10 米地面距离。比较前要确认实际地面尺度，而不是只看坐标系编号。

当前两块样区采用相邻验证条带，没有重叠像元，但仍有空间相关性。水体只来自 image1，光伏只来自 image2；直接按整幅图分训练和验证，又会导致某些类别缺失。需要新增包含这些类别的独立样区，再按区域分组。不要通过随机切片或重叠切片跨集合来人为抬高分数。

## 优化优先级与实现

### 先建立可重复的评估

固定验证集，输出全局混淆矩阵、逐类 IoU、precision、recall、F1、真实与预测像元数量。没有真值的 Qilian 全图只能作视觉检查，不能计算真实精度。颜色看起来细碎或平滑，均不能代替数值评估。

新增 `audit_classification.py` 汇总数据、已有 checkpoint 和 U-Net 历史；`evaluate_checkpoint.py` 使用统一逻辑评估 DeepLabV3 checkpoint。评估阶段不增强、不重采样标签、不平衡抽样验证集，忽略值始终为 255。

### 给新分类层充分学习机会

首版以 1e-4 对全模型统一训练五轮，新的最终分类层可能还没学好。优化入口采用参数组：骨干使用较低学习率，分割头使用更高学习率，可先冻结骨干进行短暂热身，再联合微调；使用余弦学习率衰减和梯度裁剪。

训练轮数是预算，不是精度保证。支持早停、按最佳验证 mIoU 保存，以及保存模型、优化器、调度器和随机数状态的 last checkpoint。恢复时使用相同配置；last 用于继续训练，best 用于推理，不应混淆。

优化入口继续冻结 BatchNorm 的运行统计量，支持极小批量和 ASPP 全局池化的 1×1 分支。这有稳定性收益，也可能限制遥感域统计适配；它不是经过验证的最优归一化方案。若后续改用更大有效批量、同步 BN 或 GroupNorm，应作为独立实验，并处理预训练参数兼容性。

### 提升少数类曝光，而不是只增大损失权重

现有反平方根类别权重可以继续使用。额外提供按切片类别组成的有界加权采样，增加含少数类样本出现的机会；一个 epoch 的抽样数仍为训练样本数，可能重复抽中同一切片。采样不能增加新的地理信息。

同时提供交叉熵与多类 Dice 的组合损失。交叉熵负责像元分类，Dice 补充区域重合约束。255 不参与任何项；只对当前批次真实出现的类别求 Dice 平均，缺失类别仍由交叉熵约束。不要同时盲目放大采样权重、CE 类别权重与 Dice 权重，需做消融比较。

### 添加保持影像与标签同步的增强

默认提供水平翻转、垂直翻转、90° 旋转。影像与标签必须进行同一变换，验证与测试禁止随机增强。不默认使用强烈颜色扰动，因为遥感波段值与任务语义可能相关。

### 明确架构的边界能力

本项目是 torchvision 的 DeepLabV3-ResNet50，不是 DeepLabV3+。当前 ResNet 空洞骨干输出步长为 8，不能未经检查就套用“原来是 32，改成 16 就能改善”的建议。DeepLabV3 没有 U-Net 那样的逐级浅层特征融合，对窄道路和小对象的边界恢复可能更困难，但这不能解释所有类别完全没有预测。

已用本机安装的 torchvision 实测：256×256 输入的骨干输出为 32×32，确实是步长 8。默认 ASPP 的空洞率为 12、24、36；对 32×32 特征图，较大空洞分支的部分采样点会落在填充区，但不能由此直接断言这些分支没有作用。新增 `--aspp-rates 6 12 18` 作为可控实验选项，保持输出步长不变，把参数保存到 checkpoint，推理时自动恢复；默认仍保持原参数，短程试验也未调整该项。

先优化同一架构的训练流程。后续若少数类已经被预测但边界仍明显不足，再比较更高分辨率输入、ASPP 配置、DeepLabV3+ 解码器或其他分割网络。更改空洞率后即使权重形状相同，也需要重新微调、另存 checkpoint 和验证，不能只改推理参数。改变架构则必须另存权重并重新训练，不能靠修改名称实现。

torchvision 实现与模型约定参见[官方模型文档](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.segmentation.deeplabv3_resnet50.html)和[源码](https://github.com/pytorch/vision/blob/main/torchvision/models/segmentation/deeplabv3.py)。

### 最后优化推理拼接

原入口每块 argmax 后写入中心区域。新增可选的重叠窗口概率加权融合：先 softmax，按空间权重累加各类别概率，归一化后再 argmax。还可以使用翻转 TTA，对逆变换后的概率求均值。TTA 增加计算成本，不能创造模型没学会的类别。

输出保持输入网格，额外输出最大类别概率。该概率不是经过校准的置信保证；不要用高概率推断结果一定正确。对原图未声明 NoData 的零填充，只在明确知道“所选波段全部为零即无效”时启用对应参数。

不默认做多数滤波、删除小面或道路膨胀。这些操作可能让图好看，却会抹掉窄道路、小水体与小光伏区。后处理必须在独立验证下证明收益。

## 建议的实验顺序

| 实验 | 单独改变什么 | 观察什么 |
|---|---|---|
| A | 当前 best 统一评估 | 复现 0.215706，确认评价一致 |
| B | 分组学习率、充分训练、空间增强 | 四个缺失类别是否开始出现 |
| C | B + 有界少数类采样 | 少数类召回是否提升，误检是否增加 |
| D | C + 小权重 Dice | 逐类 IoU 与区域边界 |
| E | 确认波段后比较 RGB / 四通道 | 第四通道是否提供可泛化信息 |
| F | 同一 best，比较中心拼接 / 概率融合 / TTA | 接缝与指标，推理耗时 |

一次更改多项可以生成候选配方，但不能据此认定每个改动都有帮助。固定种子用于复现，正式比较应增加多个种子，并报告独立测试区指标。本次短程试验结果见文末：只有很小的 mIoU 变化，尚无实质改善的证据。

## 运行方式

所有命令从项目根目录执行，使用装有 torch/torchvision/rasterio 的环境，例如 `conda activate python12`。保留原来的五轮权重，优化实验使用新的目录。

### 核查并复现原始结果

```powershell
python .\deeplabv3\audit_classification.py

python .\deeplabv3\evaluate_checkpoint.py `
  --dataset-dir .\deeplabv3\data\landcover_6class `
  --checkpoint .\models\deeplabv3\landcover_6class_best.pth `
  --output .\deeplabv3\out\optimization\baseline_evaluation.json `
  --device cpu
```

报告默认保存在 `deeplabv3/out/optimization/`。输入抽样检查中三个通道均未出现超过 10000 的值，因而“整体被截断成 1”不是这批训练数据已经观察到的问题；波段含义和比例假设仍需另行核实。

### 生成优化候选权重

```powershell
python .\deeplabv3\train_optimized.py `
  --dataset-dir .\deeplabv3\data\landcover_6class `
  --init-checkpoint .\models\deeplabv3\landcover_6class_best.pth `
  --output-dir .\models\deeplabv3\landcover_6class_optimized `
  --epochs 60 --batch-size 2 --device auto
```

这是从现有六类参数开始的新实验，优化器重新建立；不传 `--init-checkpoint` 则从官方参数开始。默认前两轮仅训练分割头，随后联合训练；骨干学习率 1e-5、分割头 3e-4、Dice 系数 0.3、采样权重上限比 3、早停耐心 15 轮。

输出目录非空时拒绝新实验，避免将旧 best 与新 history 混在一起。输出包括 `experiment.json`、`history.json`、`best.pth`、`last.pth`。CPU 可运行，但 60 轮成本明显高于五轮试跑；有兼容 CUDA 环境时可指定 `--device cuda`。

消融试验分别使用新输出目录。例如关闭 Dice 与类别采样，仅保留分组学习率、调度与空间增强：

```powershell
python .\deeplabv3\train_optimized.py `
  --dataset-dir .\deeplabv3\data\landcover_6class `
  --init-checkpoint .\models\deeplabv3\landcover_6class_best.pth `
  --output-dir .\models\deeplabv3\landcover_6class_ablation_b `
  --epochs 60 --sampling shuffle --dice-weight 0 --device auto
```

关闭空间增强使用 `--no-augment`，关闭 CE 类别权重使用 `--class-weighting none`。所有实验使用相同验证划分，避免看完验证结果后反复修改样本归属。

完整恢复应保留原训练参数与同一实验目录，仅将初始化参数换成 `--resume`：

```powershell
python .\deeplabv3\train_optimized.py `
  --dataset-dir .\deeplabv3\data\landcover_6class `
  --resume .\models\deeplabv3\landcover_6class_optimized\last.pth `
  --output-dir .\models\deeplabv3\landcover_6class_optimized `
  --epochs 60 --batch-size 2 --device auto
```

`--epochs` 是原计划总轮次，不是额外轮数。当前调度器按原计划设置，因此恢复时不允许改变计划轮数、采样、损失等配置；需要延长或调整配方时，以 best 作为 `--init-checkpoint` 开一个新实验。CPU 单进程随机增强、抽样与断点恢复已通过精确续训回归测试；跨设备或非确定性的 GPU 运算仍可能存在数值差异。

### 单独进行四波段实验

```powershell
python .\deeplabv3\train_optimized.py `
  --dataset-dir .\deeplabv3\data\landcover_6class `
  --bands 1 2 3 4 --scale 10000 `
  --output-dir .\models\deeplabv3\landcover_6class_4band `
  --epochs 60 --device auto
```

必须先确认四个波段的物理含义与顺序。此命令重新从官方三通道参数构造四通道模型：前三通道卷积核加第四通道 RGB 核均值，再整体乘 3/4 以控制初始响应幅度。第四通道归一化初值使用 RGB 均值/标准差的平均值，只是可复现的初始化约定，不代表该光谱通道的真实统计分布。参数随 checkpoint 保存，训练与推理共享；后续可以基于训练数据估计更合适的统计量后另行实现和比较。

新权重仍兼容原来的 `remote_sensing_inference.py`。原始三个通道 checkpoint 无需转换；旧的训练入口仍限定 RGB，四通道请使用新增入口。

### 对优化权重统一评价

```powershell
python .\deeplabv3\evaluate_checkpoint.py `
  --dataset-dir .\deeplabv3\data\landcover_6class `
  --checkpoint .\models\deeplabv3\landcover_6class_optimized\best.pth `
  --output .\deeplabv3\out\optimization\optimized_evaluation.json `
  --device auto
```

`ce_loss` 是未加权交叉熵按全数据有效像元汇总的结果，便于跨实验比较；训练 `objective` 是批次 CE+Dice 组合目标的记录，两者不要混为同一个指标。旧脚本使用加权 CE，不能把两者损失值直接比较。

### 使用概率融合做分类

```powershell
python .\deeplabv3\infer_optimized.py `
  --image .\Unet\DATA\Qilian.tif `
  --checkpoint .\models\deeplabv3\landcover_6class_optimized\best.pth `
  --output .\deeplabv3\out\optimization\qilian_classification.tif `
  --confidence .\deeplabv3\out\optimization\qilian_max_probability.tif `
  --tile-size 256 --stride 128 --device auto
```

默认使用 checkpoint 中的训练窗口尺寸，stride 默认半窗口。可添加 `--tta`，但每个窗口需要四次前向推理；建议先不开，确认效果和耗时后再比较。`--zero-is-nodata` 仅在已确认所选波段全零均为无效填充时使用。

临时概率数组使用磁盘映射，约占 `(类别数+1)×宽×高×4` 字节；Qilian 六类需要约 500 MiB 暂存空间。`--scratch-dir` 可以指定有足够空间的临时目录。输出逐块写入，不在内存中持有整幅浮点概率数组，但操作系统仍可能缓存部分映射页。分类、权重和最大概率文件不允许同路径，也不覆盖已有输出。

融合/TTA 后的评价应使用真正对应的分类栅格与真值。下面给出单个验证切片的可执行例子；只衡量该切片，不代表全验证集：

```powershell
python .\deeplabv3\infer_optimized.py `
  --image .\deeplabv3\data\landcover_6class\val\images\image1_r000_c001.tif `
  --checkpoint .\models\deeplabv3\landcover_6class_optimized\best.pth `
  --output .\deeplabv3\out\optimization\val_tile_fused.tif `
  --tile-size 256 --stride 128

python .\deeplabv3\evaluate_raster.py `
  --prediction .\deeplabv3\out\optimization\val_tile_fused.tif `
  --truth .\deeplabv3\data\landcover_6class\val\masks\image1_r000_c001_mask.tif `
  --class-names road built_up cropland bare_land water solar_farm `
  --output .\deeplabv3\out\optimization\val_tile_fused_metrics.json
```

不要对整幅 image1 的预测和完整人工标签统计后称为“验证精度”，因为其中大部分区域参加了训练。正式比较应逐个验证切片累计混淆矩阵，或在独立测试区域使用整幅真值。
